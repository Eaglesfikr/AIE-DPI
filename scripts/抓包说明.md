# 抓包说明

采集建议详见 [docs/数据标注约定.md](../docs/%E6%95%B0%E6%8D%AE%E6%A0%87%E6%B3%A8%E7%BA%A6%E5%AE%9A.md) 第 3 节。

## 快速上手（本机缺工具时）

Windows 上抓包可用 Wireshark（自带 tshark/编辑 pcap），或安装 Npcap + tshark 后用命令行：

```powershell
# 在共享热点主机侧抓手机流量，保存为 pcapng/纯 pcap
tshark -i "WLAN" -w data/raw/batch_YYYYMMDD/social_wechat.pcapng

# 只抓特定主机（手机 IP）过滤，减少噪声：
tshark -i "WLAN" -f "host 192.168.x.x" -w ...
```

## 规划批次

按「应用 × 平台 × 行为」组织原始抓包：

```
data/raw/batch_20260918/
├── wechat/android/text_chat.pcapng
├── wechat/ios/voice_call.pcapng
├── whatsapp/pc/chat.pcapng
└── non_social/...            # 网页/视频/系统更新等对照类
```

整理好后用 `scripts/建库.py` 生成 manifest。
