# 题目4：基于智能化辅助分析对应用及精细化行为进行特征挖掘识别的研究

**一、题目背景**

随着加密流量的日益增长，TLS1.3/QUIC及私有加密协议的应用普及，使得加密应用及行为的精细化识别变得更加困难；另外应用的频繁升级导致特征变化，当前的分析手段很难进行快速跟进。如何使用智能化辅助分析工具和算法，来帮助高效的发现应用及精细化行为网络流量的各维度特征(包括基础特征分析及高纬度的特征分析)，并基于相关的识别维度，来指导高性能DPI分析引擎的工程实现。通过高度智能化、及高复杂度的辅助分析工具及算法来分析和总结特征，再结合简单高效的DPI分析引擎工程实现，推动大规模网络应用流量精细化识别的实用化的突破。

**二、题目描述**

本课题需要结合 TLS 1.3/QUIC/私有协议等加密流量场景解决应用识别与精细化行为区分难题，核心任务是形成一个“智能化加密流量特征挖掘工具”和 一个配套的“高效DPI规则识别引擎”，两者可以独立工作，同时在识别维度上也是相互配合的。

“智能化加密流量特征挖掘工具”基于智能化算法与特征工程挖掘，从加密流量中自动提取基础及高维可解释特征，并基于少量样本能快速智能总结出可用的高效特征刻画维度和可行识别方案，并输出规则文件(该规则文件可以直接作为“高效DPI规则识别引擎”的输入)。

“高效DPI规则识别引擎”则通过定义一套与智能化挖掘工具提供的规则文件相配套的高效DPI识别引擎，来实现应用类型识别、用户精细化动作判定、匿名工具流量检测。

这套机制可以用来解决的识别场景包括但不限于：社交应用(Facebook、X/Twitter、Instagram)发文字贴行为识别、IM(微信、Whatsapp等)是语音通话还是视频通话行为识别、IM(微信、Whatsapp等)发文字消息聊天行为识别等；以及高度加密混淆的Tor、Psiphon、Session 等匿名工具流量的识别。

本课题需要完整实现以下6个核心功能：

**[智能化加密流量特征挖掘工具]**

1. 加密流量解析与会话重建：支持 TLS 1.3/QUIC等加密协议解析能力，支持基于TCP/UDP等私有加密协议的通用解析能力；具备乱序、重传包检测与处理能力，完成流量会话重组。
2. 基础特征维度提取：从加密流量样本中提取各个维度的信息，不限于基础协议信息、握手指纹、流统计、流段统计、时序行为、协议结构等。
3. 高级维度提取和生成：基于基础维度信息，提取或生成更高维度的流量刻画信息；
4. 可用的特征维度和可行识别方案智能分析总结：能基于基础维度特征和高级维度特征可以智能总结出可用的特征维度和可行的识别方案。并生成规则文件。

 

 **[高效DPI规则识别引擎]**

1. 定义形成一套与挖掘工具配套的可解释、成体系、逻辑严谨的DPI规则引擎；
2. 基于挖掘工具生成的规则，DPI进行高效运行。并输出识别结果。

**三、考察选手加密流量分析、特征工程、智能算法应用及工程化能力，挑战内容如下：**

1.特征挖掘工具的总结的特征维度输出有效率80%以上；经过人工修正后可用率90%以上。

2.在题目中提到的识别场景中，识别召回率≥98%，识别准确率≥95%，识别精确率≥95%，假阳率≤5%。

3.各场景需要在Android、IOS、PC平台具备跨平台的适应性。

**四、交付件**

1. 智能化加密流量特征挖掘工具和配套DPI识别引擎源代码。
2. 工具技术说明书：架构设计、协议解析、特征提取、算法原理、模块实现详细描述。
3. DPI引擎技术说明书：特征定义文档与 DPI 引擎实现详细描述。
4. 测试报告、部署与使用手册。
5. 标注数据集（即需要选手自行整理标注数据集，并提交）。

**五、评价方式**

请根据提供的流量测试集与 PCAP 数据集，利用智能化特征挖掘与分类算法，实现课题目标，评判标准如下：

1. 特征维度有效性与可用性：特征维度丰富度、有效性、可解释性、对 DPI 引擎的指导价值，以及生成规则可用性。
2. 特征维度通用性：形成的特征维度，不限于当前已列出的场景识别，还对其他场景的识别具备一定的通用性。
3. 特征维度创新性：是否有创新的特征提取维度和方法、识别模型算法、协议优化思路等。
4. 识别效果与性能：应用及精细化行为场景识别召回率、准确率、精确率、假阳率是否达标。
5. DPI的性能：规则文件在DPI的实现上是否兼顾性能，达到指标要求。
6. 报告与文档质量：说明书、测试报告、特征文档是否清晰完整，代码可运行、可复现。
7. 编程与系统实现能力：代码质量、模块化程度、运行效率、工具易用性。
