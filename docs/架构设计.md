# 架构设计（阶段 0 定稿 · 阶段 1 细化）

## 1. 总体架构

```
                        ┌─────────────────────────────────────────────┐
                        │        智能化加密流量特征挖掘工具 (离线)        │
                        │                                             │
  data/raw (PCAP)  ──▶  │  ① parser/  加密流量解析与会话重组            │
                        │  ② features/ 基础+高级特征维度提取            │
                        │  ③ analyzer/ 特征智能分析·识别方案总结        │
                        │  ④ rule_gen/ 规则文件生成                    │
                        └──────────────────────┬──────────────────────┘
                                               │ │ 规则文件 (rules/*.yaml)
                                               ▼ │
                        ┌─────────────────────────────────────────────┐
                        │         高效 DPI 规则识别引擎 (在线)           │
                        │  加载规则 → 分层匹配（低代价优先/命中短路）      │
                        │  → 输出识别结果（应用类型/行为/置信度）         │
data/raw (实时/离线流) ─▶ │                                             │
                        └─────────────────────────────────────────────┘
```

- **接口契约（关键）**：挖掘工具输出 → **规则文件 schema** → 引擎输入。规则文件必须可解释、成体系、逻辑严谨，且引擎无需复杂计算即可匹配。

## 2. 模块职责（阶段 1 详细设计时补齐）

### 2.1 特征挖掘工具 `src/feature_miner/`

- **parser/**：PCAP 读取；TCP 序列号乱序/重传处理与会话重组；UDP/QUIC 会话切分；TLS 记录层基础解析。
  - `session.py` — 会话对象：五元组、起止时间、包列表、方向标注
  - `pcap_reader.py` — PCAP/PCAPNG 读取
  - `tls.py` — TLS 握手指纹提取（SNI、ALPN、cipher、JA3/JA3S）
- **features/**：基础特征（流统计、流段统计、时序行为、协议结构）+ 高级特征（包长序列、burst 序列、周期特征、关联特征）。
  - `base.py` / `advanced.py` / `feature_store.py`（特征字典与命名规范）
- **analyzer/**：特征有效性与区分度分析（信息增益/SHAP 等，小样本快速总结）；输出候选特征清单 + 可行识别方案。
- **rule_gen/**：把选中特征转为规则文件（YAML schema）；产出规则覆盖率自检。

### 2.2 DPI 规则引擎 `engine/dpi_engine/`

- **loader.py** — 解析规则文件（校验 + 编译为内部匹配结构）
- **matcher.py** — 分层匹配器：低代价规则优先、命中短路、规则组与连接状态维护
- **result.py** — 识别结果对象与应用类型枚举

## 3. 数据分级与目录约定

| 目录 | 内容 | 是否入库 |
|---|---|---|
| `data/raw/` | 原始 PCAP（按采集批次组织） | ✗（大文件） |
| `data/processed/` | 会话 JSON / 特征 CSV 中间结果 | ✗ |
| `data/labeled/` | 标注数据集（manifest CSV + 标注 pcap/会话） | 交付件，另行管理 |
| `rules/` | 规则文件（YAML）+ 说明 | ✗（可再生成，留 README） |

## 4. 工程约定

- 语言：Python 3.10+；规则 schema 用 YAML（可解释、易人工修正）。
- 模块化：每个子目录一个职责，公共接口在 `__init__.py` 暴露。
- 特征命名：`维度_子维度_统计` 三段式（如 `flow.pkt_len.mean`、`tls.ja3`）。
- 所有运行产出可复现：固定随机种子、记录版本号与数据 hash 到报告。

## 5. 依赖决策（阶段 0）

- 解析层首选 **scapy**（纯 Python、可扩展私有协议解析、支持 pcap 与流重组）。
- QUIC/TLS 1.3 的深度解析在阶段 1 视解析深度需要再引入补充手段。
- 分析层 **scikit-learn + xgboost**：先求可解释的重要性，避免黑盒；规则生成走"决策路径 → 阈值规则"方向。
